# Abandoned but not Forgotten

Interactive platform for the **2026 NASA Space Apps Challenge** theme:

**Storytelling about NASA's Discarded Equipment on the Moon and Mars**

## Purpose

An open web platform that uses NASA public data to:

- Show exact locations of abandoned hardware on interactive zoomable maps (Mars, Moon, Earth)
- Display 3D representations of the equipment
- List real failure factors (dust, extreme cold, mechanical issues, power loss)
- Provide concrete prevention strategies for future missions

Built for education and mission design insight. Light theme, not dark blue.

## Features

- Interactive Leaflet maps (OpenPlanetaryMap for Mars)
- Three.js 3D viewer for Spirit, InSight, Surveyor 3
- Catalog + detailed failure analysis & prevention lists

## Data

Coordinates and facts from public NASA sources. 3D models are procedural (real NASA GLB files can be swapped in later).

Educational open use for the challenge.
